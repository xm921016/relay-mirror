# 错误码速查表（管理员值班手册）

> 场景：群成员在登记页登记时遇到报错，或号池任务异常，你查这张表就知道原因和怎么回复。
> 标注 ✅ 的是本项目实测过的；其余来自社区通用经验（NeteaseCloudMusicApi 等），方向可靠。

---

## 一、网易登录 / 验证码类（成员短信登录时最常见）

| code | 含义 | 原因 | 给成员的话术 |
|---|---|---|---|
| 200 ✅ | 成功 | — | — |
| **8860** ✅ | 登录失败，请确认是否本人账号 | **登录风控**：请求来自陌生环境（机房 IP）或重试太多次，网易拒绝下发登录态。账号本身没问题 | 等 5-10 分钟**只重试一次** → 不行直接用「方式二」粘 MUSIC_U 登记 |
| **8810** | 您当前的网络环境存在安全风险 | 登录风控（和 8860 同类），多见于扫码登录/陌生设备 | 同 8860，改用方式二或找管理员扫码代登记 |
| **301** ✅ | 未登录 / cookie 已失效 | MUSIC_U 过期或被降权；未登录调了需登录的接口 | 重新取一次 cookie（无痕模式）再登记 |
| **460** | 校验失败 | 加密参数错误/过期，或触发人机验证 | 稍后重试；反复出现换方式二 |
| **400** | 请求参数错误 | 手机号/验证码格式不对、验证码填错 | 检查手机号 11 位、验证码是否最新一条 |
| **503** | 请求过于频繁 / IP 高频 | 短时间点太多次（发验证码、登录都不宜连点） | 等 10 分钟再来，操作放慢 |
| 403 "请稍后再试" ✅ | 瞬时风控（签到接口也见过） | 网易临时限流 | 过一会儿重试即可，非故障 |

## 二、二维码登录状态码（/api/qr_check 返回）

| code | 含义 |
|---|---|
| 800 | 二维码已过期（重新获取） |
| 801 | 等待扫码 ✅ |
| 802 | 已扫码，待手机上点确认 |
| 803 | 授权登录成功（返回 cookie）✅ |
| 502 | 扫码后偶发，需加 noCookie 参数（我们 Worker 已处理） |

## 三、受限会话（不报错但"看起来坏了"，最容易被误判）✅

**特征**：`account/get` 返回 **code=200 但 profile/account 为空**。
**本质**：cookie 被"本机 IP + 机房 IP 混用"触发降权，变成受限会话——**还能听歌**（每日推荐正常），但身份接口隐藏。
**处理**：不用换号！无痕模式重新登录取新 cookie，用管理员脚本 `setck` 换掉即可。
**注意**：run.py 判活会自动放行受限会话（每日推荐二次验证），所以号池里受限号照常干活，只是查不到昵称。

## 四、登记页自带文案（Worker 返回，看到就知道原因）✅

| 页面提示 | 原因 | 处理 |
|---|---|---|
| 群口令错误 | 口令不是 `music2026`（注意大小写、别带空格） | 核对口令 |
| 该账号已登记过（每个账号限登记一首歌） | 同一账号/手机号已在池里 | 已登记过，无需重复；想换歌找管理员 |
| 该手机号/账号已登记过 | 同上（按手机号匹配） | 同上 |
| 只支持单曲，歌单/专辑会被拒绝 | 粘的是歌单/专辑分享链接 | 重新分享**单曲**页链接 |
| 请填写 MUSIC_U / 请先填写正确的 11 位手机号（显示实际识别位数） | 输入问题（带空格/+86/全角数字等） | 按提示的位数检查输入 |
| 校验失败，请重试（带诊断码） | CF 机房到网易瞬时异常；cookie 形状合法时会**降级放行**（provisional），明天任务自动复验 | 重试一次；已放行的等明天复验 |
| 服务器内部错误：xxx（HTTP 500） | Worker 异常，**xxx 就是真实错误信息** | 把这段话截图发给管理员 |
| HTTP 1101 | Worker 内部抛异常（旧版遗留，现已全局兜底显示真实错误） | 同上，报错原文发管理员 |

## 五、运维侧报错（你自己的脚本/部署，非成员问题）✅

| code / 报错 | 出处 | 含义 |
|---|---|---|
| 405 Method not allowed (CF API) | Cloudflare | API 令牌缺对应写权限（如 Workers Secrets 写需要 Workers:Edit） |
| 10036 (CF API) | Cloudflare | workers.dev 子域已设置过，API 不能改名，只能 Dashboard 改 |
| 10068 (CF 部署) | Cloudflare | 上传的 Worker 没有事件处理器（格式用错：模块/经典格式搞混） |
| 403 Request forbidden (GitHub API) | GitHub | fetch 没带 User-Agent（Worker 调 GitHub 已修） |
| resync 群口令错误 | 号池管理.py | 口令读取源不对（已改为优先读 KV 的 GROUP_PASS 键） |
| Actions 绿勾但没干活 | GitHub Actions | 脚本捕获异常后正常退出；**必须看日志关键行**（pool_size/完成!/失败N次） |
| 播放 0 次 | cron-relay 任务 | 符合设计：added=今天的号次日才入池 |

## 六、快速判断口诀（发给群里也行）

> - **8860 / 8810** = 网易嫌环境陌生 → 等等再试一次，不行换**方式二粘 cookie**
> - **301** = cookie 失效 → 无痕重登取新 cookie
> - **口令错误** = 检查 music2026 有没有输错
> - **歌单被拒** = 只能分享单曲
> - **其他看不懂的** = 截图发管理员

## 七、附：号池管理.bat 乱码问题（00:20 实录）✅

| 现象 | 真根因 | 解法 |
|---|---|---|
| 双击 bat 报 "浜掑惉缇ゅ彿...不是内部或外部命令"（乱码命令） | bat 是 UTF-8 保存，cmd 按 GBK 逐行解析；`chcp 65001` 只改控制台显示，**改不了解析层** | **中文 bat 必须 GBK 编码保存**（现号池管理.bat 已是 GBK）；不要自己用记事本另存为 UTF-8 改这个文件 |
